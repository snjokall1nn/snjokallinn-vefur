# Snjókallinn vefur

GitHub repository for the Snjókallinn website.

## Source

The current site was created in ChatGPT Work / Sites. This repository is being prepared as the long-term source of truth for the website.

## Deployment

Target: GitHub Pages.

The deployment configuration will be added after the exported site source is added, because the correct GitHub Pages setup depends on whether the project is plain HTML/CSS/JavaScript or a build-based project such as Vite/React.

## Workflow

1. Edit the website source in this repository.
2. Commit changes to `main` (or use a feature branch + pull request for larger changes).
3. GitHub Pages deploys the production build after deployment is configured.
